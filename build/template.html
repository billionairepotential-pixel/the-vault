Get the .ydk file

  1. Click . It saves to your Downloads folder as deck.ydk.
  2. Move the file into your simulator's deck folder, or import it from the simulator's deck menu.

Download blocked? Click , paste it into Notepad (on Mac, TextEdit with Format › Make Plain Text), and save it with a name ending in .ydk. In Notepad, set "Save as type" to "All files" so it doesn't save as .txt.
